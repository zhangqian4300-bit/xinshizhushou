## 1. 架构概述

### 1.1 系统架构图

```
┌─────────────────────────────────────────────────────────────────────┐
│                           用户端                                      │
│                    (小程序 / Web / App)                               │
└─────────────────────────────┬───────────────────────────────────────┘
                              │ HTTPS
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│                        云服务器 (阿里云/腾讯云)                         │
│                                                                      │
│  ┌─────────────────┐         ┌─────────────────┐                    │
│  │   Nginx         │         │ OpenClaw Gateway │                   │
│  │  (反向代理)      │         │   (AI 服务网关)   │                   │
│  │  Port: 80/443   │         │   Port: 19000    │                   │
│  └─┬───────────────┘         └─┬───────────────┘                    │
│    │                           │ WebSocket                           │
│    ↓                           ↓                                     │
│  ┌─────────────────┐         ┌─────────────────┐                    │
│  │ 心石清理师 Agent │←────────│   Claude API    │                    │
│  │   (Node.js)     │         │   (AI 模型调用)  │                    │
│  │   Port: 3000    │         └─────────────────┘                    │
│  └─┬───────────────┘                                                │
│    │                                                                 │
│    ↓                                                                 │
│  ┌─────────────────┐                                                │
│  │    MongoDB      │                                                │
│  │   Port: 27017   │                                                │
│  └─────────────────┘                                                │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.2 组件说明

| 组件 | 版本要求 | 端口 | 作用 |
|-----|---------|------|------|
| OpenClaw Gateway | 最新版 | 19000 | AI 服务网关，连接 Claude API |
| MongoDB | 6.0+ | 27017 | 用户数据、对话记录、养护计划存储 |
| 心石清理师 Agent | Node.js 18+ | 3000 | 业务逻辑，API 服务 |
| Nginx | 1.24+ | 80/443 | 反向代理，SSL 证书，负载均衡 |

### 1.3 数据流向

```
用户发送消息
    → Nginx (HTTPS → HTTP)
    → 心石清理师 Agent (处理业务逻辑)
    → OpenClaw Gateway (WebSocket 连接)
    → Claude API (生成 AI 回应)
    → 返回给用户
```

## 3. OpenClaw Gateway 安装

### 3.1 什么是 OpenClaw Gateway

OpenClaw Gateway 是一个 AI 服务网关，负责：
- 管理 WebSocket 连接
- 调用 Claude/GPT 等 AI 模型
- 处理设备身份认证
- 管理会话和上下文

### 3.2 获取 OpenClaw

OpenClaw Gateway 需要从官方渠道获取安装包或源码。

**假设你已经拥有 OpenClaw Gateway**，以下是安装步骤：

```bash
# 创建目录
mkdir -p ~/openclaw
cd ~/openclaw

# 如果是源码方式
# git clone <OpenClaw Gateway 仓库地址>

# 如果是安装包方式
# unzip OpenClaw-Gateway.zip
```

### 3.3 OpenClaw Gateway 配置

创建配置文件 `gateway-config.json`：

```json
{
  "port": 19000,
  "deviceIdentity": {
    "deviceId": "your-device-id",
    "deviceKey": "your-device-key"
  },
  "aiProvider": {
    "type": "anthropic",
    "apiKey": "your-claude-api-key"
  },
  "logging": {
    "level": "info"
  }
}
```

### 3.4 启动 OpenClaw Gateway

```bash
# 方式 1：直接运行（假设有可执行文件）
./openclaw-gateway --config gateway-config.json

# 方式 2：Node.js 方式
node gateway.js

# 方式 3：后台运行
nohup ./openclaw-gateway > gateway.log 2>&1 &
```

### 3.5 验证 Gateway 运行

```bash
# 检查端口
netstat -tlnp | grep 19000

# 或使用 lsof
lsof -i :19000

# 测试连接（如果有测试脚本）
curl http://localhost:19000/health
```

### 3.6 使用 systemd 管理 Gateway

创建服务文件 `/etc/systemd/system/openclaw-gateway.service`：

```ini
[Unit]
Description=OpenClaw Gateway AI Service
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/openclaw
ExecStart=/opt/openclaw/openclaw-gateway --config gateway-config.json
Restart=always
RestartSec=10
StandardOutput=syslog
StandardError=syslog
SyslogIdentifier=openclaw-gateway

[Install]
WantedBy=multi-user.target
```

管理命令：

```bash
sudo systemctl daemon-reload
sudo systemctl start openclaw-gateway
sudo systemctl enable openclaw-gateway
sudo systemctl status openclaw-gateway
```

## 4. MongoDB 安装

### 4.1 使用 Docker 安装（推荐）

```bash
# 创建数据目录
mkdir -p ~/data/mongodb

# 启动 MongoDB
docker run -d \
  --name xinshi-mongo \
  -p 27017:27017 \
  -v ~/data/mongodb:/data/db \
  -e MONGO_INITDB_ROOT_USERNAME=admin \
  -e MONGO_INITDB_ROOT_PASSWORD=your-password \
  mongo:6

# 验证运行
docker ps | grep mongo
```

### 4.2 使用 docker-compose（更推荐）

创建 `mongo-compose.yml`：

```yaml
version: '3.8'

services:
  mongo:
    image: mongo:6
    container_name: xinshi-mongo
    ports:
      - "27017:27017"
    volumes:
      - ~/data/mongodb:/data/db
    environment:
      MONGO_INITDB_ROOT_USERNAME: admin
      MONGO_INITDB_ROOT_PASSWORD: your-password
    restart: always
    healthcheck:
      test: echo 'db.runCommand("ping").ok' | mongosh localhost:27017/test --quiet
      interval: 10s
      timeout: 5s
      retries: 5
```

启动：

```bash
docker compose -f mongo-compose.yml up -d
```

### 4.3 创建应用数据库和用户

```bash
# 连接 MongoDB
docker exec -it xinshi-mongo mongosh -u admin -p your-password

# 在 mongosh 中执行
use xinshi-assistant

# 创建应用用户
db.createUser({
  user: "xinshi-app",
  pwd: "app-password",
  roles: [
    { role: "readWrite", db: "xinshi-assistant" }
  ]
})

# 退出
exit
```

### 4.4 MongoDB 连接字符串格式

```
mongodb://xinshi-app:app-password@localhost:27017/xinshi-assistant?authSource=admin
```

## 6. 配置详解

### 6.1 环境变量配置 (.env)

创建 `.env` 文件：

```bash
# ====== 服务配置 ======
SERVER_PORT=3000
NODE_ENV=production

# ====== MongoDB 配置 ======
# 格式：mongodb://用户名:密码@主机:端口/数据库?authSource=认证数据库
MONGODB_URI=mongodb://xinshi-app:app-password@localhost:27017/xinshi-assistant?authSource=admin

# ====== OpenClaw Gateway 配置 ======
# 方式 1：本机运行，指定端口
OPENCLAW_GATEWAY_PORT=19000

# 方式 2：指定完整地址（如果 Gateway 在其他服务器）
# OPENCLAW_GATEWAY_URL=ws://gateway-server-ip:19000

# 方式 3：指定主机和端口
# OPENCLAW_GATEWAY_HOST=192.168.1.100
# OPENCLAW_GATEWAY_PORT=19000

# ====== 安全配置 ======
# 允许的 CORS 域名（逗号分隔）
# 小程序域名、Web 域名、API 域名
ALLOWED_ORIGINS=https://your-domain.com,https://miniapp-domain.com

# Rate Limit 配置（防滥用）
RATE_LIMIT_WINDOW_MS=60000      # 时间窗口：1分钟
RATE_LIMIT_MAX_REQUESTS=100     # 最大请求数：100次/分钟

# ====== 日志配置 ======
LOG_LEVEL=info                  # debug, info, warn, error
```

### 6.2 docker-compose.yml 配置说明

项目已包含 `docker-compose.yml`，内容如下：

```yaml
version: '3.8'

services:
  # MongoDB 服务
  mongo:
    image: mongo:6
    container_name: xinshi-mongo
    ports:
      - "27017:27017"
    volumes:
      - mongo_data:/data/db
    environment:
      MONGO_INITDB_ROOT_USERNAME: admin
      MONGO_INITDB_ROOT_PASSWORD: password123  # 请修改密码！
    healthcheck:
      test: echo 'db.runCommand("ping").ok' | mongosh localhost:27017/test --quiet
      interval: 10s
      timeout: 5s
      retries: 5

  # 心石清理师 Agent
  xinshi-agent:
    build: .
    container_name: xinshi-agent
    ports:
      - "3000:3000"
    environment:
      - NODE_ENV=production
      - MONGODB_URI=mongodb://admin:password123@mongo:27017/xinshi-assistant?authSource=admin
      - ALLOWED_ORIGINS=http://localhost:3000  # 请修改为你的域名
      - RATE_LIMIT_WINDOW_MS=60000
      - RATE_LIMIT_MAX_REQUESTS=100
      - OPENCLAW_GATEWAY_PORT=19000
    depends_on:
      mongo:
        condition: service_healthy
    healthcheck:
      test: wget --no-verbose --tries=1 --spider http://localhost:3000/health || exit 1
      interval: 30s
      timeout: 10s
      retries: 3

volumes:
  mongo_data:
```

### 6.3 重要配置修改

部署前 **必须修改** 的配置：

| 配置项 | 默认值 | 需修改为 |
|-------|-------|---------|
| MongoDB 密码 | password123 | 强密码 |
| ALLOWED_ORIGINS | localhost | 你的域名 |
| OPENCLAW_GATEWAY | localhost:19000 | Gateway 实际地址 |

## 7. 启动服务

### 7.1 启动顺序

```
1. MongoDB        → 2. OpenClaw Gateway  → 3. 心石清理师 Agent
```

### 7.2 启动命令

```bash
# 启动 MongoDB（如果使用 docker-compose）
docker compose up -d mongo
# 等待健康检查通过
sleep 10

# 启动 OpenClaw Gateway
sudo systemctl start openclaw-gateway
# 或直接运行
cd ~/openclaw && ./openclaw-gateway &
# 等待启动
sleep 5

# 启动心石清理师 Agent
docker compose up -d xinshi-agent
# 或使用 PM2
pm2 start examples/xinshi-agent.js --name xinshi-agent
```

### 7.3 一键启动脚本

创建 `start-all.sh`：

```bash
#!/bin/bash

echo "===== 启动心石清理师服务 ====="

# 1. 启动 MongoDB
echo "[1/3] 启动 MongoDB..."
docker compose up -d mongo
sleep 10

# 2. 启动 OpenClaw Gateway
echo "[2/3] 启动 OpenClaw Gateway..."
sudo systemctl start openclaw-gateway || {
    echo "使用直接运行方式启动 Gateway..."
    cd ~/openclaw && nohup ./openclaw-gateway > gateway.log 2>&1 &
}
sleep 5

# 3. 启动 Agent
echo "[3/3] 启动心石清理师 Agent..."
docker compose up -d xinshi-agent

echo "===== 服务启动完成 ====="
echo "API 地址: http://localhost:3000"
echo "健康检查: curl http://localhost:3000/health"
```

## 9. 常见问题

### 9.1 MongoDB 连接失败

**症状：**
```
[MongoDB] Connection error: Authentication failed
```

**解决：**
```bash
# 检查 MongoDB 是否运行
docker ps | grep mongo

# 检查用户密码
docker exec -it xinshi-mongo mongosh -u admin -p your-password

# 确认连接字符串格式正确
# mongodb://用户名:密码@主机:端口/数据库?authSource=admin
```

### 9.2 OpenClaw Gateway 连接失败

**症状：**
```
WebSocket connection failed
```

**解决：**
```bash
# 检查 Gateway 端口
lsof -i :19000

# 如果 Gateway 在其他服务器，检查防火墙
sudo firewall-cmd --add-port=19000/tcp --permanent
sudo firewall-cmd --reload

# 或 Ubuntu
sudo ufw allow 19000/tcp
```

### 9.3 CORS 错误

**症状：**
```
Access to XMLHttpRequest has been blocked by CORS policy
```

**解决：**
```bash
# 编辑 .env，添加你的域名
ALLOWED_ORIGINS=https://your-domain.com,https://miniapp-domain.com

# 重启服务
docker compose restart xinshi-agent
```

### 9.4 Rate Limit 触发

**症状：**
```json
{"error": "请求过于频繁，请稍后再试", "code": "RATE_LIMIT_EXCEEDED"}
```

**解决：**
```bash
# 调整限制（如果需要）
RATE_LIMIT_MAX_REQUESTS=200

# 或禁用（仅开发环境）
# 不设置 RATE_LIMIT_MAX_REQUESTS
```

### 9.5 端口冲突

**症状：**
```
Error: listen EADDRINUSE: address already in use :::3000
```

**解决：**
```bash
# 查找占用进程
lsof -i :3000

# 停止占用进程
kill -9 <PID>

# 或更换端口
SERVER_PORT=3001
```

- `error`：错误信息

### 10.2 数据备份

```bash
# MongoDB 备份
docker exec xinshi-mongo mongodump \
  -u admin -p your-password \
  --db xinshi-assistant \
  --out /tmp/backup

# 复制到本地
docker cp xinshi-mongo:/tmp/backup ~/backup/mongodb-$(date +%Y%m%d)

# 定时备份（crontab）
0 2 * * * ~/apps/xinshizhushou/scripts/backup-mongo.sh
```

创建备份脚本 `scripts/backup-mongo.sh`：

```bash
#!/bin/bash
BACKUP_DIR=~/backup/mongodb
DATE=$(date +%Y%m%d_%H%M%S)

mkdir -p $BACKUP_DIR

docker exec xinshi-mongo mongodump \
  -u admin -p your-password \
  --db xinshi-assistant \
  --out /tmp/backup-$DATE

docker cp xinshi-mongo:/tmp/backup-$DATE $BACKUP_DIR/

# 保留最近7天
find $BACKUP_DIR -type d -mtime +7 -exec rm -rf {} \;

echo "Backup completed: $BACKUP_DIR/backup-$DATE"
```
